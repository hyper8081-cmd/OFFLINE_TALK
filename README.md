# OFFLINE_TALK

iPhone同士の近距離通信を検証するネイティブiOS試作です。最低対応OSはiOS 16です。

## 現在の試作範囲

- 親機をチャンネル1〜10のいずれかで開始
- 子機が同じチャンネルの親機をBonjourで検索
- Network frameworkのピアツーピアWi-Fiを有効にして接続
- 親機側で接続した子機の台数と一覧を表示（最大4台）
- 子機側で親機と他の子機の一覧を表示
- アプリ内の端末名を設定して参加者一覧・発言者表示に使用
- 現在の発言者を表示
- 子機の切断通知
- バックグラウンド時の切断・再接続ローカル通知（許可された場合）
- 子機が選択済みの親機を再検索して自動再接続（アプリ起動中）
- アプリが前面から外れた時にPTT・連続送話を解放
- ローカルネットワーク権限の説明を表示
- 親機による発言権管理（同時に1台）
- 押している間だけPCM音声を送信するPTT
- 発言権を取得して連続送話するモード（一度に1台）
- 親機が子機の音声を他の端末へ中継

マイク音声を区間平均化して16 kHzへ変換し、モノラルPCM16で送ります。音声エンジンでは可能な場合にVoice Processingを有効にし、未送信音声は接続ごとに最大8チャンク、受信再生待ちは300 msを上限にして古い音声を破棄し、遅延の累積を抑えます。連続送話モードは一人が発言権を保持している間だけ送信します。PTT操作と自動再接続はアプリ前面表示中を対象とし、アプリが前面から外れるとPTT・連続送話を終了します。切断・再接続のシステム通知は許可された場合にバックグラウンド中だけ表示します。音質、遅延、長時間のバッファ動作、5台接続時の性能、自動再接続はいずれも実機検証前の試作です。

通信フレームはAES-GCMで暗号化し、親機が表示する128ビット参加コードを共有した端末だけが接続できます。親機と子機で同じコードを入力してください。コードはiOS Keychainに端末内だけで保存し、既存版のコードは初回起動時に移行します。親機では固定コードを使います。鍵更新、前方秘匿性、再送攻撃対策、暗号方式の第三者レビューは未実装・未確認です。実機での認証失敗動作も未検証のため、機密性が重要な通話にはまだ使わないでください。

## ビルドと実機確認

WindowsにはXcodeがないため、このワークスペース上ではiOSアプリをビルドできません。`OFFLINE_TALK.xcodeproj`をXcodeが使えるMacで開き、Signing & CapabilitiesでAppleの開発チームを設定して実機へインストールしてください。

公開リポジトリの標準macOSランナーでiOS Simulator向けにコンパイルします。`main`へのpush時と手動起動時にワークフローが動きます。実行時間は15分で打ち切り、ビルド成果物は保存しません。公開ソースのコンパイル確認であり、iPhone実機への署名・インストールや端末間通信の確認は行いません。公開リポジトリの標準ランナーは無料です（[GitHubの課金説明](https://docs.github.com/en/billing/concepts/product-billing/github-actions)）。

このmacOSランナーは、ビルド中だけGitHubが用意するクラウド実行環境です。Xcodeを遠隔操作するデスクトップではなく、USBでiPhoneをつないで署名・実機インストールする用途には使えません。

2026-11-04時点で、コミット `937d3c7` までのSimulator向けコンパイルが成功しています。最新の実行状況は[GitHub Actions](https://github.com/hyper8081-cmd/OFFLINE_TALK/actions/workflows/ios-build.yml)で確認できます。

確認時は両方のiPhoneでWi-Fiをオンにし、アプリのローカルネットワークとマイクへのアクセスを許可します。ルーター、インターネット、携帯回線を切った状態で、片方を親機、もう片方を同じチャンネルの子機として接続し、PTTを押している間の送受話を確認します。iOS 16.7.11のiPhone Xを最初に確認します。
