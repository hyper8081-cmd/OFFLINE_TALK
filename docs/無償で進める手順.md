# 費用をかけずに進める手順

更新日: 2026-11-04

## 現在地

- WindowsでSwiftソース、画面、通信設計、設定ファイルの編集を続けられる。
- このWindows環境にはXcode、Swiftコンパイラ、iOS SDKがないため、iOSアプリのビルド、署名、iPhoneへのインストールはできない。
- iOS SimulatorもmacOS上のXcodeに含まれるため、Windows単体では実行できない。
- 2026-11-04にコミット `937d3c7` のiOS Simulator向けコンパイル成功を確認。iPhone実機での音声・通信は未検証。

## 無料で使える経路

### 1. このWindowsで開発を続ける

画面・通信プロトコル・再接続・エラー処理のソースと設計資料を整える。iOS専用APIの型やOSごとの挙動はXcodeのコンパイルと実機確認が済むまで確定扱いにしない。

### 2. GitHub Actionsでシミュレータ向けコンパイル

公開GitHubリポジトリにmacOSビルドワークフローを用意しており、`main`へのpush時と手動起動時にiOS Simulator向けの署名なしビルドを行う。2026-11-04にコミット `937d3c7` のコンパイル成功を確認した。これはコンパイル確認であり、シミュレータを操作した確認やiPhoneへのインストールではない。

GitHub ActionsのmacOSランナーがこのプロジェクトで使っている「クラウドMac」に当たる。ジョブ実行中だけ用意されるビルド環境で、利用者がXcodeを遠隔操作するMacデスクトップではない。iPhoneをUSB接続して実機署名・インストールすることもできない。遠隔デスクトップ型のクラウドMacサービスは別の製品で、一般に利用料金がかかる。

費用を避けるには、GitHubの無料枠とActionsの予算・利用上限を先に確認する。非公開リポジトリの実行はアカウントの無料枠を消費し、超過時の課金設定によっては費用が発生しうる。公開リポジトリはソースが全員に見える。したがって、リポジトリの公開・アップロードは所有者が選択してから行う。

### 3. iPhone実機に無料で入れる

Appleの無料Personal Team署名で実機インストールする方法はあるが、通常はMac上のXcodeでApple Accountを登録し、アプリを署名する必要がある。無料署名には期限や機能上の制限がある。GitHub Actionsのシミュレータ向けワークフローでは代替できない。

手元または知人のMacが一時的に使えるようになった場合は、Xcodeと無料のApple Accountでビルドし、iPhone Xを先に確認する。Macがない間はWindowsで準備を続け、端末テストは保留となる。無料枠のあるMac貸出サービスを恒常的に利用できるとは限らず、無料と保証された実機テスト経路としては扱わない。

## 実機テストを始められる時の手順

1. `OFFLINE_TALK.xcodeproj`をXcodeが入ったMacで開く。
2. Deployment TargetがiOS 16.0であることを確認する。
3. Signing & CapabilitiesでPersonal Teamを選び、iPhone Xを接続して開発者モードを有効にする。
4. iPhone X (iOS 16.7.11)へインストールし、マイクとローカルネットワークを許可する。
5. iPhone 15にも同じ手順で入れ、両端末のWi-Fiをオンにする。Wi-Fiルーター、インターネット、携帯回線は切って、近距離で親機・子機の発見、接続、PTT音声、切断、再接続を確認する。
6. 2台で安定を確認するまでは、5台接続、100m、画面ロック中の継続を達成済みとしない。

## 有料クラウドMacの費用目安（2026-11-04調査）

| 方法 | 公開料金の目安 | 実機テストへの注意 |
|---|---:|---|
| MacinCloud Pay-As-You-Go | US$1/時間、またはUS$4/日 | 日単位は24時間利用。時間単位は日ごとの利用時間を合算して1時間単位に切り上げ。残高が尽きると自動補充されるため、ログアウトと補充条件の確認が必要。 |
| MacinCloud Managed | US$25/月から | Xcodeを使えるリモートMac。iPhoneからRDP接続できるが、TestFlight配布にはApple Developer Programが必要。 |
| MacStadium Mac mini | US$109/月から | 月単位のMacレンタル。短時間だけ使う用途では割高。 |
| AWS EC2 Mac | 料金はリージョン等で変動 | Mac専用ホストの最低割当が24時間。短時間の試用向けではない。 |

為替を2026-11-04の約1ドル=157.56円で換算すると、MacinCloudは約158円/時間または約630円/日、MacStadiumは約17,200円/月からです。税、カード会社の為替手数料、サービス側の追加条件は含みません（[USD/JPYの当日データ](https://www.investing.com/currencies/usd-jpy-historical-data?end_date=2026-11-04&st_date=2026-11-04)）。

TestFlightまたは登録端末への配布にはApple Developer Programが必要で、Appleの公開料金は年US$99（現地通貨額は登録時に表示）です。したがって、クラウドMacを1時間だけ借りてTestFlightで実機確認する場合でも、未加入なら初年度の追加費用は概算で約US$100（約15,800円）に税・為替手数料を加えた額です。TestFlightは開発者メンバーシップ内で提供されます（[Apple Developer Programの料金](https://developer.apple.com/jp/programs/enroll)、[配布要件](https://developer.apple.com/documentation/xcode/distributing-your-app-for-beta-testing-and-releases)）。

クラウドMacの従量課金には自動補充があるプランがあります。利用時間を超えると追加請求が発生しうるため、追加のクラウドMacは契約していません。現状の公開GitHub ActionsでのSimulator向けコンパイルは、公開リポジトリの標準ランナーを使う限り無料です（[GitHub Actionsの課金説明](https://docs.github.com/en/billing/concepts/product-billing/github-actions)）。

## このプロジェクトでの次の作業

実機テストまで、iOS 16互換性を意識したソースレビュー、エラー処理、画面と設計資料の整備を続ける。公開リポジトリへのpushでGitHub ActionsのSimulator向けコンパイルが自動実行される。公開ソースを許容できない場合は、push前にリポジトリを非公開に変更し、Actionsの無料枠と予算を確認する。
